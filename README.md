# FotoStock Manager

Quero que crie um sistema de gerenciamento de entrada e saida de produtos que possa receber produtos apenas tirando a foto, ou importando documentos com as informacoes da compra de cada um.
Quero um front-end bem destinado, que traga minimalismo e renome
